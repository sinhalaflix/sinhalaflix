🔑 How to get a GitHub Personal Access Token (Free & 1-minute):
  1. Go to GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic) (or click here).
  2. Click "Generate new token (classic)".
  3. Set Note: SinhalaFlix Admin and check the repo checkbox (Full control of private/public repositories).
  4. Click Generate token, copy the generated token (starts with ghp_), and paste it above.
  5. Your token is safely stored only inside your browser's private storage on this device.
